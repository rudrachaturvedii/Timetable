How to Use Scheduler Pro

  1. Download the Template: Click the "Download Template" button to get an Excel file formatted for our system.
  2. Fill in the Data: Open the Excel file and fill out the sheets:
    • Courses: Map courses to professors and student batches with min/max hours.
    • Absences: Specify dates when professors or batches are unavailable.
    • Settings: Define the term start/end date and working days.
  3. Upload and Validate: Select your saved Excel file and upload it. The system will check for missing columns or bad data and tell you exactly what to fix.
  4. Generate Schedule: Once data is validated, generate the optimal schedule. (Available in next stage).
